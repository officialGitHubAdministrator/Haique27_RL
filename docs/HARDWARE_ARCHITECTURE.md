# 硬件架构与电气接线规范 (Hardware Architecture & Wiring)

## 1. 硬件连接拓扑与引脚定义 (Pinout Mapping)

飞控采用 **MicoAir743 v1.3 (STM32H743VIT6)**，30.5×30.5mm 飞塔布局：

```text
+-------------------------------------------------------------------------+
|                              MicoAir743 v1.3                            |
|                                                                         |
|  [UART1 / TELEM1] ────── TX1/RX1/GND ──────> Jetson / RK3588 (ROS 2/DDS)|
|  [UART3 / GPS]    ────── TX3/RX3/SCL/SDA ──> M9N GPS + 磁罗盘模块       |
|  [UART6 / RC]     ────── RX6/TX6/5V/GND ───> ELRS 2.4G 接收机 (CRSF)    |
|  [ESC PWM 1-4]    ────── M1, M2, M3, M4 ───> 60A 4-in-1 电调 (DShot600)  |
|  [POWER IN]       ────── VCC(5V), GND ─────> 独立 5V/5A 降压稳压模块     |
+-------------------------------------------------------------------------+
```

### 串口引脚详细映射表

| 端口编号 | 飞控物理丝印 | 对应硬件外设 | 通信协议 / 波特率 | 备注 |
| :---: | :---: | :---: | :---: | :--- |
| **UART1** | `TX1`, `RX1`, `GND` | 机载伴随计算机 (Jetson/RK3588) | UART @ `921600 bps` | 运行 Micro-XRCE-DDS-Agent |
| **UART3** | `TX3`, `RX3`, `SCL`, `SDA`, `5V`, `GND` | M9N GPS + 罗盘 | NMEA/U-Blox @ `115200 bps`, I2C | 卫星定位与外部航向参考 |
| **UART6** | `RX6`, `TX6`, `5V`, `GND` | ExpressLRS (ELRS 2.4G) | CRSF @ `420000 bps` | 遥控链路输入与双向遥测 |
| **ESC Port** | `M1`~`M4`, `TLM`, `BAT` | 60A 4-in-1 电调 | DShot600 + 电调遥测 | 双向 DShot 支持 RPM 滤波 |

## 2. 电源分配与防断电安全设计

* **动力源**: 6S LiPo 22.2V (满电 25.2V, 截止 21.0V) 3300mAh ~ 4000mAh 100C。
* **分级稳压设计**:
  1. **动力级 (高压大电流)**: 电池直接经 XT60 接 60A 4-in-1 电调。
  2. **飞控与接收机供电**: 独立 6S 宽压输入转 5V/5A DC-DC 降压模块（LC 滤波），专供 MicoAir743、ELRS 接收机与 GPS。
  3. **机载计算端供电**: 独立 6S 转 12V/5A (或 5V/5A) 稳压模块专供机载计算机，输入端加装 $1000\mu\text{F}$ 低 ESR 电解电容，杜绝电机猛收油门时的瞬态反峰浪涌。
